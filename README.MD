# Description of the project

This project collects data about my daily routine . I want to understand how I spend my time and identify patterns in my daily activities. I will record activities such as study,  sleeping, eating and leisure time. I will use Python, SQLlite, Pandas and Matplotlib to analyse my data and create visualisations. I also created an interactive menu that allows users to view data, display charts.

# Instructions for use

The project will be run using Python. The application will load the collected CSV data into a database, analyse the data and display results .

Data Analysis and Findings

1. Weather Analysis

The weather analysis shows that rainy days were the most common weather condition, with 12 days out of 20 (60%). Sunny days were recorded on 7 days (35%), while 1 day (5%) had both rain and sunshine.

2. Meals Analysis

The meals analysis shows that I usually had 2 meals per day. I had 2 meals on 11 days, 3 meals on 7 days and 1 meal on 2 days.
